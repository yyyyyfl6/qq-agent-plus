# 轻量知识库

这不是完整的 RAG：没有向量库、没有 embedding、没有文档解析服务。它只读 `data/knowledge` 下的 `.md` / `.txt`，切片后按关键词 + 中文二元组检索，回答时带来源文件名。适合群规、FAQ、产品手册这类**少量、稳定、纯文本**的资料。

## 开启

控制台「设置 → 平台 → 知识库」可以开关、改目录和切片参数，并查看索引状态；也可以直接上传 `.md` / `.txt` 文件、粘贴正文、删除文档和重建索引。也可以手改配置：

```json
{
  "knowledge": {
    "enabled": true,
    "dir": "",
    "maxResults": 4,
    "chunkChars": 900,
    "overlapChars": 120
  }
}
```

- `dir` 留空 = `data/knowledge`；也可以写绝对路径。
- 支持 `.md` / `.txt`，单文件最大 2MB，最多 500 个文件；子目录最多 3 层。
- 文件改了会自动重建索引（按 mtime/size 判断），不用重启。
- 控制台 `GET /api/knowledge` 可以看当前目录、文件数、切片数和上次建索引时间。

## 工具

开启后会给模型一个 `knowledge_search` 工具：

```json
{ "query": "禁言最长多久", "limit": 4 }
```

返回 `source`（相对路径）和 `snippet`。工具描述要求模型带上来源；没命中就直说，不许编。

## 边界

- 不做语义检索：问法和原文差太远可能搜不到；这时候换关键词。
- 不做 PDF/DOCX/表格/图片 OCR：先转成 markdown 或纯文本再放进来。
- 不做权限隔离：知识库是全局的，所有群都能搜到。需要按群隔离时，用多个实例或等后续版本。
- 没有 embedding Key 依赖，所以不会因为 Key 失效而整条链路坏掉。
- 语料很大（几千份、经常更新、需要语义召回）时再考虑完整 RAG；当前实现刻意保持轻。
