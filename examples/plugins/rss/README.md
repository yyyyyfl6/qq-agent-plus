# RSS 订阅 rss

**这个博客最近更新了啥** —— 给一个 RSS / Atom 地址，返回最新几篇的标题、链接、时间。
**插件不自带任何源**，地址每次由调用方给。

## 能做什么

- **任意 RSS / Atom 源**：博客、新闻站、播客都行
- **要几条可调**（默认 5，最多 20）
- **只给清单**：标题 / 链接 / 时间；要不要看正文由模型决定（它还有 `web_fetch`）

## 群里怎么问

- 「这个博客最近更新了啥」+ 订阅地址
- 「帮我看看这个 RSS 有没有新文章」
- 「这个播客最近三期的标题」

## 配置

**不用填** —— `capabilities` 里没有 `config`，这个插件不读设置。

## 边界

- **解析是「够用」级别**：零依赖、不引 XML 库（v1 只收零依赖插件），遇到不规则的源可能解析不全
- 给的地址是个网页而不是 feed 时**明确报错**（提示「这多半是博客首页」），不硬解析成空条目
- 响应过大被宿主截断时，结果里带 `truncated: true` 并说明只解析了前面一段
- 没有条目会明确报错，不会静默返回空；日期认不出就原样给出，不编造时间
- 只读，不能发言；不做定时推送 / 订阅管理

## 装

控制台左侧「插件」→ 安装 → 启用。手工：把本目录拷到 `$DATA_DIR/plugins/rss/`。
