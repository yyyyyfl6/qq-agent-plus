# 翻译 translate

**这句英文什么意思**、**帮我翻成日语** —— 中 / 英 / 日 / 韩互译。
走 MyMemory 公开接口，**不需要 Key**（DeepL / 百度 / 腾讯那几家都要）。

## 能做什么

- **四个语种互译**：中（`zh-CN`）、英（`en`）、日（`ja`）、韩（`ko`）
- **不用指定源语言**：只给原文和目标语言，它自己判断
- **一次一小段**：上游按**字节**限长 500 字节（约 166 个汉字，或 500 个英文/数字），超了会提示分段

## 群里怎么问

- 「把『今天真热』翻成日语」
- 「这句英文什么意思：It works on my machine」
- 「帮我翻成英文：明天下午三点开会，改到 404」

## 配置（可选）

- `defaultTo` —— 没说目标语言时用哪个，默认 `zh-CN`。想默认中译英就改成 `en`

```json
{ "plugins": { "settings": { "translate": { "defaultTo": "en" } } } }
```

## 边界

- **译文质量有限**：MyMemory 是公开的免费记忆库，专业内容请人工校对
- 它有个已知的坑：**有时会把原文原样返回**（HTTP 200、不报错）。这种情况结果里带 `warning`，
  不会把「没翻」讲成「翻完了」
- 匿名额度按天算，用完当天不可用，第二天恢复
- 只读，不能发言

## 装

控制台左侧「插件」→ 安装 → 启用。手工：把本目录拷到 `$DATA_DIR/plugins/translate/`。
