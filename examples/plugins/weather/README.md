# 天气 weather

**问一句就有答案**：上海今天要不要带伞、Tokyo 明天冷不冷。
数据来自 Open-Meteo 公开接口，**不需要 Key**，装上就能用。

## 能做什么

- **今天的实况**：温度、体感、天气现象、湿度、风速，以及今天的最高/最低温与降水概率
- **未来三天**：每天的最高 / 最低温与降水概率（从明天起算）
- **随口问**：不说城市就用配置里的默认城市
- **城市名**：中国城市用中文没问题；**境外城市请用英文名**（Tokyo / New York / Seoul）—— Open-Meteo 的中文地理编码只收录了中国城市，查「东京」会匹配到江苏的一个村子

## 群里怎么问

- 「上海今天要带伞吗」
- 「Tokyo 未来三天冷不冷」
- 「北京现在几度」

## 配置（可选）

- `defaultCity` —— 没说城市时用哪个，默认 `Beijing`

```json
{ "plugins": { "settings": { "weather": { "defaultCity": "上海" } } } }
```

## 边界

- **不能在群里自己发言**：没有 `send` 能力；想每天早上定时播报要等 v1.1
- 只读：不写任何东西。请求经宿主（内网地址被拦、有体积上限与超时）
- 不缓存：每次都是现查，所以数据是最新的

## 装

控制台左侧「插件」→ 安装 → 启用。手工：把本目录拷到 `$DATA_DIR/plugins/weather/`。
