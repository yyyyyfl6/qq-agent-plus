# 出行规划

目标：把“想去哪玩”变成一份能直接照着走的行程，而不是景点清单。

步骤：

1. 先确认三件事：出发地、日期/天数、预算与同行人（带小孩/老人会改变强度）。缺哪项就问哪项，一次问完，不要连续追问。
2. 用 `web_search` 查交通、天气、近期闭馆/限流信息；需要细节再 `web_fetch` 打开官方页面。价格与营业时间要注明“以官方为准”。
3. 给 2–3 套方案，每套写清：怎么去、住哪一片、每天 2–3 个点、大致花费区间、适合谁。
4. 明确不替用户订票/订房；不要编造车次、票价或营业时间。
5. 最后用 `send_message` 发一条结论，控制在 6–10 行；细节放后面分条。

边界：

- 不推荐需要实名/签证材料代办的灰色服务。
- 天气、票价、开放时间可能变化，必须提醒复核来源。
