# 评论分析

目标：把一堆评论压成“主要观点 + 争议点”，而不是挑几条最热闹的复述。

步骤：

1. B 站视频优先用 `plugin_call` 调 `bilibili__video`（withComments=true）和 `bilibili__read`（热门评论/弹幕/字幕），确认能拿到多少条样本；非 B 站页面才用 `web_fetch`。拿不到就说拿不到。
2. 把评论按观点聚类，给出每类的大致占比或“多数/少数”，但不要编造精确百分比。
3. 区分三类内容：
   - 事实/体验：具体使用感受、可核对的信息；
   - 情绪：喜欢、失望、愤怒，但不等于事实；
   - 争议：双方都有人支持、还没有定论的点。
4. 每条观点最多引一句短评，去掉昵称、头像、QQ 号等个人信息。
5. 用 3–5 条短句发群里；最后给一句“如果你只想知道值不值得”，用一句话回答。

边界：

- 不抓取登录后内容，不绕过平台限制。
- 不把少量极端评论说成“大家都这么认为”。
- 不分析具体某个人，只分析观点分布。
